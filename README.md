# AI Invoice Control Room

A portfolio concept and working prototype: a supervision layer for AI-run accounts payable. It sits between an invoice-extraction tool and company financial records, and decides what can proceed, what needs a person, and what is blocked.

- `docs/BRIEF.md`: the build brief (source of truth)
- `docs/Control_Room_Build_Brief_v5.docx`: Word snapshot of brief v5
- `CLAUDE.md`: working rules for Claude Code

All data is synthetic. Not a deployed finance product.
